# Simple Calculator

This is a basic calculator web app made using **HTML**, **CSS**, and **JavaScript**. It is designed to perform basic arithmetic operations easily and quickly.

---

## 📌 Uses

- ✅ Helps in doing basic calculations like addition, subtraction, multiplication, division, and modulus.
- ✅ Useful for students and beginners to understand how JavaScript works with HTML.
- ✅ Can be used as a mini project or part of a portfolio.

---

## ⚙️ How It Works

- The calculator takes input from button clicks (numbers and operators).
- The display updates with every click using JavaScript.
- `=` evaluates the full expression using `eval()`.
- `C` clears the whole input, and `DEL` removes the last number or symbol.

---

## 🛠 Technologies Used

- HTML – for structure
- CSS – for styling (style11.css expected)
- JavaScript – for calculator logic

---

## 📂 Project Files

- `index11.html` – Main file with calculator layout
- `script11.js` – Contains JavaScript functions
- `style11.css` – Stylesheet

---

## 🚀 How to Use

1. Download or clone the repository.
2. Open `index11.html` in any web browser.
3. Start clicking the buttons and perform calculations.
